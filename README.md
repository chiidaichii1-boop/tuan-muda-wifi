The word is **Ghosting** — my Wi-Fi vanishes mid-call, mid-download, mid-sentence, exactly like a date who ghosts you. Funny at once, true to how home Wi-Fi actually behaves, and fresh against the usual "slow" / "weak" / "buffering".
